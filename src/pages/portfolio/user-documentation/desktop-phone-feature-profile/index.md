# Desktop Phone Feature Profile

## Overview

This sample demonstrates focused, task-oriented documentation designed to explain a single product feature independently from a larger user guide.

## Project Summary

| | |
|---|---|
| Audience | Desktop Phone Users |
| Document Type | Feature Profile|
| Industry | Telecommunications|
| Tools | Adobe Illustrator, FrameMaker |
| Skills | Technical Writing, Content Design, Editing, Information Architecture|

## Challenge

The existing feature-profile template was outdated and did not support the concise, focused documentation experience the team wanted to provide. Access to SMEs was also limited.

## Solution

I collaborated with an editor and members of the information architecture team to restructure the feature-profile template using a more minimalist approach aligned with company branding. The revised format focused each document on a single feature so users could quickly find and understand the information they needed.

## Result

The completed feature profile was published on the company website as customer-facing content highlighting the technology, its capabilities, and potential applications.
