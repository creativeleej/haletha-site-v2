# PHP If Else Tutorial

## Overview

A developer-focused tutorial explaining PHP conditional logic through syntax examples, code walkthroughs, and step-by-step instruction.

## Project Summary

| | |
|---|---|
| Audience | Prospective Online Software Development Students |
| Document Type | Technical Blog Post|
| Industry | Education Technology |
| Tools | Microsoft|
| Skills | Technical Research, Technical Writing, Content Strategy, Tutorial Writing, Editing |

## Challenge

The client needed in-depth programming content that could attract prospective students while differentiating its articles from the large volume of existing material about PHP, Java, and SQL Server.

## Solution

I researched the target audience and existing programming content to identify common topics and information gaps. I then developed distinctive angles for familiar subjects and structured the articles to make technical concepts approachable and useful to prospective students.

## Result

Within 30 days, I researched and wrote six in-depth articles covering PHP, Java, and SQL Server, producing approximately 30 pages of technical content for the client's website.
