# Docs-as-Code Project

## Overview

A self-directed docs-as-code project built with Docusaurus, Markdown, Git, and GitHub to create a technical-writing portfolio that demonstrates modern documentation workflows as well as writing samples.

---

## The Problem

My previous portfolio displayed writing samples but did not demonstrate experience with modern documentation workflows such as structured authoring, version control, static-site generation, and docs-as-code publishing.

---

## Goal

Build a technical-writing portfolio that serves as both a showcase of my work and evidence of my docs-as-code capabilities.

---

## Approach

I built the site in Docusaurus using Markdown-based content, reusable page structures, static assets, Git version control, GitHub hosting, local testing, and iterative information-architecture improvements.

## Result

Created a working docs-as-code portfolio containing developer documentation, user documentation, technical communications, and project case studies within a structured, version-controlled publishing workflow.
